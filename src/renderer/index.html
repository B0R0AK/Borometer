BOROMETER Throne and Liberty

Borometer reads the combat log the game writes after every fight and shows you what carried your damage – and where seconds went missing.

Read only: Borometer opens a file the game writes itself. No access to the game, no account, nothing is uploaded.

First, get the game writing logs

  1. 1Settings
  2. 2Shortcuts
  3. 3Ring Menu
  4. 4Add Combat Meter

Then switch it on once from the ring menu. From then on the game writes a file every time a fight ends.

Borometer could not find your combat log folder on its own. Pick it once and it is remembered.

    How this log is being read

    Borometer reads the column roles from the shape of the data. If you change a role, it recalculates every number.

    You have not set a Damage column yet. Borometer needs one before it can calculate anything.

    Without a column set as Time there are no seconds and so no DPS — damage and hits still add up.

    With no column set as Skill, every hit lands in one unnamed row, so Rotation and the per-skill numbers have nothing to tell apart.

    Which rows count as damage you dealt

    Rows of an unticked kind are left out of every number.
