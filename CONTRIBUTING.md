# Contributing

Thank you for wanting to help. Borometer takes issues only: bug reports and ideas,
in English or German. Pull requests are closed unread. The code is developed in a
private working repository and published here once per release, so a pull request
could not be merged as it stands.

- Bugs: use the bug form. Say which version and download you use (installer,
  portable, zip, or the page in a browser) and what you saw.
- Combat logs: only shortened, and only with ids and numbers. Replace every
  character name, yours and other players', before you attach anything.
- Never suggest anything that reaches into the game: no memory reading, no
  hooks, no overlays, no automation. Borometer reads the log file and nothing else.
- Security problems go through [SECURITY.md](SECURITY.md), not an issue.

Deutsch: Issues gern auf Deutsch. Pull-Requests werden nicht angenommen; Logs nur
gekürzt und ohne Charakternamen anhängen.
